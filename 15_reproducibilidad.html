15. Reproducibilidad y bibliografía#

Entorno#

Todos los resultados del entregable 3 se calcularon en el entorno conda ml_venv (Python 3.9.25, Windows 11, 12 hilos lógicos, GPU NVIDIA RTX 3050 de 6 GB). Las versiones exactas están en requirements.txt; las principales: numpy 1.25.2, pandas 2.1.0, scipy 1.11.2, scikit-learn 1.3.0, imbalanced-learn 0.12.4, xgboost 2.1.3, optuna 4.1.0, deap 1.4.1, shap 0.46.0, lime 0.2.0.1, statsmodels 0.14.0, arch 7.0.0, faiss-cpu 1.9.0 y jupyter-book 1.0.4.

Las cifras del modelo base del entregable 2 (capítulo 5) se calcularon con scikit-learn 1.2.2 en el entorno del entregable 1 y no se recalcularon.

Registro de experimentos#

  • results/nested/<tarea>/<modelo>__<balanceo>__<optimizador>__f<pliegue>.json: una corrida por combinación y pliegue externo (700 archivos), con hiperparámetros elegidos, puntaje interno, métricas externas, tiempos de búsqueda, reajuste y predicción, semilla y el historial de las 16 evaluaciones.

  • results/master_clf.csv y results/master_reg.csv: tabla maestra, una fila por combinación (112 y 28) con media y desviación estándar de cada métrica externa, tiempo total, número de evaluaciones, semilla e hiperparámetros finales.

  • results/outer_folds_*.csv: una fila por celda; results/test_*.csv: métricas en la prueba; results/seeds.csv: corridas de sensibilidad a semillas.

Cómo correr todo#

pip install -r requirements.txt
set OSHA_DATA_DIR=<carpeta con el CSV de OSHA>          # o export en Linux/macOS
python scripts/run_nested.py all 11      # validación anidada de las 140 combinaciones (reanudable)
python scripts/run_final.py all 11       # reajuste de cada combinación y evaluación en la prueba
python scripts/run_seeds.py 11           # sensibilidad a semillas
python scripts/build_notebooks.py        # convierte nb_src/*.py en jbook/*.ipynb y los ejecuta
jupyter-book build jbook
ghp-import -n -p -f jbook/_build/html    # publica el libro en la rama gh-pages

Cada celda de la validación anidada se guarda al terminar, así que una corrida interrumpida se reanuda sin repetir trabajo. Los capítulos guardan sus cálculos costosos (SHAP, recalibración, bootstrap, experimentos de costo) en results/cache/, que no se versiona; la primera ejecución los calcula.

Dashboard del entregable 2#

La carpeta dashboard/ es la del entregable 2 sin cambios (Dash/Plotly, desplegado en Render desde un repositorio aparte). El entregable 3 no lo modifica.

Candado de la prueba. data.classification_sets() y data.regression_sets() devuelven la prueba como LockedTest (cualquier acceso lanza PermissionError). Para reproducir las cifras ya publicadas de los capítulos 9 a 13 y 18 se fija OSHA_ALLOW_TEST=1; ningún resultado del proyecto final la usa.

Corridas del proyecto final (todas reanudables):

python scripts/build_fullcodes.py               # códigos completos, OIICS y empleador (no se versiona; caps. 18-20 y pytest)
python scripts/run_paired.py 10                 # experimento pareado (original + 7 benchmarks; se usó 3×5), results/pareado/
python scripts/analyze_paired.py 4              # TPE anidado del combinador, ablación, pruebas y figuras (cap. 20)
python scripts/build_artifacts.py todo          # artefactos + metadata.json + prueba de ida y vuelta
python scripts/build_dashboard_data.py          # tablas del dashboard (EDA, líderes, fuera de pliegue, SHAP global)
python scripts/build_dashboard_extras.py        # tablas del dashboard del proyecto final (candidatos, pliegues, sensibilidad)
python scripts/complejidad_secr.py              # complejidad empírica de SECR (cap. 19)
python scripts/build_master_table.py            # tabla maestra de experimentos (140 + pareado + original)
python scripts/literatura/buscar.py             # consultas de la revisión de literatura (cap. 16.5)
python scripts/build_notebooks.py 20_validacion_estadistica
pytest tests                                     # pruebas del ensamble, de SECR, del candado y de PT-bagging
cd dashboard_final && pytest tests && python app.py

Herramienta exploratoria (no produce cifras del libro). scripts/jugar_con_secr.py reajusta SECR en segundos sobre las predicciones ya guardadas de cada pliegue (results/pareado/original/*.npz) con los hiperparámetros que se le pasen (--gate, --lam, --alpha, --steps) y muestra la BA por pliegue. Sirvió para estudiar el modelo y preparar la sustentación. Sus cifras no se usan para elegir hiperparámetros, porque eso sería mirar los pliegues del veredicto (sección 19.9); el modelo reportado es el que eligió la TPE interna.

Entornos. Las corridas usan ml_venv (arriba). El dashboard usa Python 3.11.9 con las versiones de dashboard_final/requirements.txt: las mismas librerías numéricas que entrenaron los artefactos, más dash 2.18.2, dash-bootstrap-components 1.6.0, plotly 5.24.1 y gunicorn 23.0.0. Se probó localmente en el entorno conda dash_e3, con esas versiones.

Tabla maestra de experimentos. results/tabla_maestra_experimentos.csv tiene una fila por experimento:

  • las 140 combinaciones del entregable 2, con las métricas del bucle externo (5 pliegues), los tiempos, la semilla y los hiperparámetros;

  • los 7 benchmarks del experimento pareado y el modelo original, con media y d.e. de sus pliegues, tiempos y semillas.

Uso de la prueba. Ningún resultado de los capítulos 13b, 19, 20 y 21 ni del dashboard usa la prueba de octubre a diciembre.
